# Markdown to HTML Lab Viewer

A lightweight viewer that renders a hands-on lab Markdown file as a single scrolling HTML page (TOC, alerts, copyable code blocks).

Labs are loaded with a `?lab=` query parameter (GitHub folder/file URL or raw Markdown URL).

## Authoring labs (not in this repo)

This repository is the **lab viewer** (runtime). Lab authoring skills and instructor docs live in:

**[roitraining/roi-course-authoring-template](https://github.com/roitraining/roi-course-authoring-template)**

Use that template to write labs (`labs/lab-NN-slug/README.md`). Do not maintain the Lab Generator skill in this viewer repo.
